# 현황판 위젯

할 일 목록(`STATUS.md` 파일 하나)을 바탕화면 오른쪽 위에 **Liquid Glass 느낌의 위젯**으로 띄워 두는 Windows용 프로그램이에요.
평소에는 작은 알약으로 접혀 있다가, 커서를 올리면 펼쳐져요.

Claude Code와 함께 쓰면 Claude가 같은 파일을 읽고 고쳐서, **Claude가 하던 일과 내가 할 일이 한 목록에** 모여요. Claude 없이 그냥 할 일 위젯으로 써도 돼요.

![접힌 알약과 펼친 현황판](docs/screenshot.png)

## 이런 걸 할 수 있어요

- 위 3개는 **"지금 할 것"** 카드로 크게, 나머지는 순위대로 아래에 보여 줘요.
- 마감이 있는 일은 **D-5** 처럼 남은 날짜가 붙어요.
- 네모를 체크하면 줄이 그어지고, **빗자루** 버튼을 누르면 줄 그은 일이 한꺼번에 완료함으로 가요.
- 줄을 **잡고 끌어서** 순서를 바꿔요. 보류나 완료 칸 위에 놓으면 그 칸으로 들어가요.
- **⋯ 버튼이나 오른쪽 클릭**으로 지금 할 것으로 올리기 · 보류 · 완료를 할 수 있어요.
- **+ 버튼**으로 새 일을 넣어요(종류를 고르고 Enter).
- 완료함에서 **되살리기**나 **영구 삭제**를 할 수 있고, 실수하면 **되돌리기** 버튼으로 돌아가요.
- 바꾼 내용은 바로 `STATUS.md`에 저장돼요. 메모장으로 파일을 고쳐도 위젯이 몇 초 안에 따라 바뀌어요.

## 설치하기 (Windows 10·11)

1. [Node.js](https://nodejs.org/ko) **LTS 버전**을 설치해요. 설치 화면은 다음만 눌러도 돼요.
2. 이 페이지 위쪽의 초록색 **Code → Download ZIP**을 눌러 내려받고, 원하는 곳에 압축을 풀어요.
3. 압축 푼 폴더를 열고, 위쪽 주소창에 `powershell`이라고 쓰고 Enter를 눌러요. 그 폴더에서 파란 창이 열려요.
4. 그 창에 아래를 붙여 넣고 Enter를 눌러요. 위젯을 그리는 프로그램(Electron, 약 160MB)을 내려받느라 1~2분 걸려요.

   ```
   npm install
   ```

5. 끝나면 폴더의 **`현황판 실행.cmd`**를 더블클릭해요. 화면 오른쪽 위에 알약이 나타나요.
6. 컴퓨터를 켤 때마다 자동으로 띄우고 싶으면, 작업 표시줄 오른쪽 아래 **체크 모양 아이콘을 오른쪽 클릭 → "로그인할 때 자동 실행"**을 켜요.

> 처음 실행할 때 Windows 보안 경고가 뜨면 "추가 정보 → 실행"을 누르면 돼요.

## 쓰는 법

| 하고 싶은 것 | 방법 |
|---|---|
| 잠깐 보기 | 알약에 커서를 올려요. 치우면 다시 접혀요. |
| 펼친 채로 두기 | 알약을 **눌러요**. 다른 창 위에도 떠 있어요. 위쪽의 **˄**를 누르면 다시 자동으로 접혀요. |
| 줄 긋기 | 네모 칸을 눌러요. |
| 완료함으로 보내기 | 빗자루 버튼(줄 그은 것 한꺼번에), 또는 ⋯ → 완료로 |
| 순서 바꾸기 | 줄을 잡고 끌어요. |
| 보류 | ⋯ → 보류, 또는 줄을 "보류" 위에 놓아요. |
| 새 일 넣기 | + 버튼 → 내용 쓰고 Enter |
| 위젯 옮기기 | "현황판" 글자를 잡고 끌어요. |
| 파일을 직접 열기 | 맨 아래 파일 이름을 눌러요. |
| 끄기 | 체크 모양 아이콘 오른쪽 클릭 → 끝내기 |

체크 모양 아이콘의 메뉴에는 항상 위에 두기, 펼친 채로 두기(다음에 켤 때도), 다른 현황판 파일 고르기, 새 현황판 만들기, 위치 처음으로, 다시 그리기도 있어요.

## Claude Code와 같이 쓰기

위젯은 컴퓨터에 `C:\Users\(내 이름)\.claude` 폴더가 있으면 **`~/.claude/STATUS.md`** 를 현황판으로 써요(없으면 예시 파일로 새로 만들어요).
Claude가 매번 이 파일을 보고 고치게 하려면, `~/.claude/CLAUDE.md`(없으면 새로 만들어요)에 아래를 붙여 넣으세요.

```markdown
## 작업 현황판
- 지금 걸려 있는 일은 `~/.claude/STATUS.md`에 있다. 바탕화면 위젯이 이 파일을 읽고 쓴다.
- 일을 새로 맡거나, 끝내거나, 막히면 이 파일도 같이 고친다. 사용자가 위젯으로 바꿨을 수 있으니 고치기 전에 다시 읽는다.
- 형식은 파일 맨 위 규칙을 따른다. 끝난 일은 줄을 지우지 않고 `[x]`로 바꾸고 `(완료 MM/DD)`를 붙여 `## 완료` 맨 위로 옮긴다.
- 새 일은 우선순위를 판단해 알맞은 자리에 넣는다. 애매하면 위 3개 바로 아래에 넣는다.

@~/.claude/STATUS.md
```

마지막 줄의 `@~/.claude/STATUS.md`는 Claude Code가 새 세션을 열 때마다 현황판 내용을 함께 읽게 해 줘요.

## Claude 없이 쓰기

`.claude` 폴더가 없으면 **`문서\현황판\STATUS.md`** 를 예시 내용으로 만들어서 써요.
다른 위치의 파일을 쓰고 싶으면 아이콘 메뉴의 **"다른 현황판 파일 고르기…"**나 **"새 현황판 만들기…"**를 눌러요. 고른 파일은 다음에 켤 때도 기억해요.

## 파일 형식

```markdown
## 할 일
- [ ] [마감] 보고서 제출 — 12/20 오후 6시까지
- [ ] [대기] 디자인 시안 고르기 — A안과 B안 중 하나

## 보류
- [ ] [대기] 책장 정리 — 주말에

## 완료
- [x] [진행] 현황판 위젯 설치 (완료 1/1)
```

- 칸은 `## 할 일`, `## 보류`, `## 완료` 세 개예요. `## 할 일`은 **위에 있을수록 먼저** 할 일이에요.
- 한 줄 = `- [ ] [태그] 제목 — 설명 ← 참고`. 태그는 **마감 · 진행 · 대기 · 설치 · 확인** 중 하나예요. 설명과 참고는 없어도 돼요.
- `[마감]` 줄은 처음 나오는 날짜(월/일)로 D-day를 세요.
- 자세한 규칙은 [`STATUS.example.md`](STATUS.example.md) 맨 위에 있어요.

## 알아 두면 좋은 점

- 유리 너머로 비치는 그림은 **바탕화면 그림을 위젯 안에 맞춰 깔아서** 만든 거예요. 그래서 "항상 위에 두기"로 다른 창 위에 띄우면, 그 창 대신 바탕화면 그림이 비쳐 보여요.
- 글꼴은 인터넷에서 [프리텐다드](https://github.com/orioncactus/pretendard)를 불러와요. 인터넷이 안 되면 맑은 고딕으로 보여요.
- 켜 두면 메모리를 약 130MB 써요.
- 투명한 부분이 하얗게 변하면 아이콘 메뉴의 **"다시 그리기"**를 눌러 주세요. 무슨 일이 있었는지는 `%APPDATA%\현황판 위젯\events.log`에 남아요.
- 파일을 바꿀 때마다 바로 전 내용이 `STATUS.md.bak`으로 남아요.

## 고치고 싶은 사람에게

| 파일 | 하는 일 |
|---|---|
| `main.js` | 창, 트레이 메뉴, 파일 읽고 쓰기, 바탕화면 그림 |
| `status.js` | `STATUS.md` 읽기·쓰기와 각 동작(체크, 옮기기, 완료 등) |
| `index.html` · `widget.css` · `widget.js` | 위젯 화면 |
| `preload.js` | 화면과 `main.js` 사이 연결 |

`npm start`로도 켤 수 있어요(이때는 검은 창이 같이 떠요).
